## 🎯 Quick Start (5 minutes)

### 1. Configure
```bash
# Edit .env with your Revive credentials
cp backend/.env.example backend/.env
# Set: REVIVE_HOST, REVIVE_USERNAME, REVIVE_PASSWORD
```

### 2. Verify
```bash
npm run build
curl http://localhost:3001/api/ad-server/health
```

### 3. Use
```typescript
// Inject and use
constructor(private reviveApi: ReviveApiService) {}

const result = await this.reviveApi.pushCampaignToRevive(
  accountId, accountName, campaignPayload
);
```
